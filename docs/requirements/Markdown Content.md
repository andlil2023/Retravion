## Implementation Status

## Requirements

### REQ-CONTENT-001 — Content in Markdown fields

**Parent need:** UN-CONTENT-001

**Requirement:** The system shall enable users to include paragraphs, tables, and Mermaid diagrams in content authored in Markdown fields across the application, including Markdown fields introduced for future entities.

**Acceptance criteria:**
- Mermaid content is rendered as a diagram in the preview.
