**Requirements:** [Relationship Management](../requirements/Relationships.md)

Version-dependent cases require the approved versioning specification and implementation in #132–134. Ordinary-link cases belong to #135–140. Provenance cases are explicitly deferred to #141–143; Test Cases require #144 and subsequent approved implementation.
