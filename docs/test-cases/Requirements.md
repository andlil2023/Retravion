## Deferred Verification

Centralized graphical relationship management, Requirement–User Need links, parent–child relationships, automatic ID suggestions, application Test Cases, separate verification-criteria fields, and Product revision integration are outside this increment. Verification of released-version protection belongs to future revision work; approval alone is not release. These repository test specifications do not implement the deferred Test Case feature.

Field limits, exact Unicode comparison semantics, search matching beyond case-insensitivity, and MCP transport/authentication details require implementation planning. These cases neither settle those details nor claim executed automation. Database verification during implementation must use disposable PostgreSQL containers as required by the repository workflow.
