## Deferred Verification

Released Product revision references and protection of exact referenced need versions require verification when revision integration is designed and implemented. Centralized mapping, remote MCP, deletion, and ownership transfer are outside this increment. Exact transport, authentication mechanism and comparison semantics require implementation decisions; these cases do not claim those decisions or completed automation.
