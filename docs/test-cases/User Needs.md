## Deferred Verification

Released Product revision references and baseline-specific protection require separate runtime verification when revision integration is implemented, following REQ-LINK-009 and TC-LINK-025–029. Eligible reopening is specified above; release protection is approved future behavior, not implemented functionality. Centralized mapping, remote MCP, deletion, and ownership transfer are outside this increment. Exact transport, authentication mechanism and comparison semantics require implementation decisions; these cases do not claim those decisions or completed automation.
