# UN-AUDIT-02 — Inspect Application Activity

**Need:** As an administrator, I need to find and trace relevant application activity, including changes to Products, user accounts and access, so that I can investigate events and support regulatory inspections.

For Product changes, traceability must survive changes to or reuse of the user-visible Product ID and retain the Product ID and field values as they were at the event. Unauthorized attempts must be traceable without retaining submitted field values. Administrators need to open individual events from the audit list and inspect their recorded information, including initial Product values or changed fields with old and new values, without executing untrusted content.
